重设计前后对照

现状（拼凑）

  • 一页两套渲染：innerHTML 整块重刷 + 手写静态 HTML
  • 资质区块满屏内联 style，不走 token、不能主题化
  • 6 种卡片方言，背景透明度 0.58/0.38/0.35/0.32 各异
  • 两套 Tab（下划线 vs 胶囊）+ 三种标题写法
  • 所有设置平铺一大片，无分区导航

重设计后（成体系）

  • 声明式配置 → TS 组件渲染，按行局部更新
  • 全部 .set-* class + var(--*) token，零内联颜色
  • 唯一 .set-card；两级高度（surface / surface-h）
  • 统一 .set-tabs + .set-seg + 统一 section 标题
  • 左侧 6 分区导航，窄屏退化为横向 chip
